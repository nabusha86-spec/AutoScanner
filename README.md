# AutoScanner
AutoScanner Trader — интеллектуальный Android-автотрейдер для Pocket Option. Анализирует графики в реальном времени, распознаёт свечи, валютные пары и ценовые движения, самостоятельно определяет BUY/SELL и экспирацию от нескольких секунд до 3 минут.
